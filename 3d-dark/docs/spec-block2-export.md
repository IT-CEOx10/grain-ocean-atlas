# Блок 2. Экран «Страны назначения» — задание

Интерактивный экран выставочного приложения для сенсорной панели 1920×1080
(Windows, офлайн, с последующей упаковкой в EXE). Содержание — 3D-глобус
с маршрутами экспорта российского зерна по странам и годам. Язык — русский.

## Исходные данные

**`data/данные по странам на 27.08.2026.xlsx`**, лист «по странам»:
столбец A — названия, столбцы B..M — годы 2014..2025 (строка 4 — заголовки),
значения в тысячах тонн. Иерархия задаётся отступом ячейки A
(`cell.alignment.indent`):

- отступ 0 — группа продукции (5 групп: зернобобовые культуры, зерновые культуры,
  корма/комбикорма и их компоненты, масличные культуры, продукты переработки зерна;
  строка «Общий итог» пропускается);
- отступ 1 — продукт (пшеница, ячмень и т. д.);
- отступ 2 — страна под этим продуктом.

Всего 164 уникальные страны, 248 строк-заголовков (5 групп + 242 продукта + итог).
Лист «по годам» — те же группы и продукты без стран, плюс столбец 2026;
он используется только для сверки, в таймлайн выводятся 2014..2025.
Файл читается через openpyxl. В названиях стран встречается неразрывный пробел —
пробелы нормализуются.

**`data/geo/countries-110m.json`** — TopoJSON world-atlas 2.0.2
(`objects.countries`, `id` — числовой код ISO 3166-1 строкой,
`properties.name` — английское название).

## Состав работ

1. **`tools/build_data.py`** — читает xlsx и пишет `data/export.json`:
   список годов; по каждой стране — название, iso (числовой id из topojson или null),
   lat/lon, суммарный объём по годам, разбивка по продуктам по годам
   (только ненулевые, по убыванию), группа продукта; по каждому году сводка —
   общий объём, число стран с объёмом больше нуля, число групп продукции,
   топ-3 страны. Скрипт должен перезапускаться при замене xlsx: обновление данных
   без правки кода (требование ТЗ). Числа округляются до трёх знаков.

2. **`data/countries_ru.json`** — ручной справочник: русское название из xlsx →
   `{ iso (как в topojson), lat, lon (столица или крупный порт), en }`.
   Покрыты все 164 страны. Для территорий, которых нет в world-atlas 110m
   (Абхазия, Южная Осетия, Сингапур, Мальта, Бахрейн, Маврикий, Сейшелы, Коморы,
   Кабо-Верде, Британские Виргинские острова и т. п.) `iso` = null,
   но lat/lon обязательны. `build_data.py` останавливается с понятным списком,
   если для страны нет записи.
   Отдельно выверены: «Новая Гвинея» = Папуа — Новая Гвинея, «Македония» =
   Северная Македония, «Молдавия» = Молдова, «Белоруссия» = Беларусь,
   «Киргизия» = Кыргызстан, «Республика Корея» = Южная Корея,
   «Конго, Демократическая Республика» и «Республика Конго» — разные страны.

3. **Приложение**: `index.html`, `src/` (обычный JavaScript, без модулей),
   `styles/`, `vendor/` (three.js и topojson-client скачаны локально,
   версии зафиксированы в README). Без сборщиков и фреймворков.
   Данные загружаются один раз при старте. Для разработки — `python3 -m http.server`.

4. **`tools/build_dist.py`** — собирает `dist/index.html`: один файл, куда
   инлайнятся CSS, JS, vendor-библиотеки и оба JSON (данные как
   `<script type="application/json">`), чтобы файл открывался по `file://`
   без сервера и мог быть опубликован как веб-страница.
   Никаких внешних ссылок и fetch в dist.

5. **`config.json`** (инлайнится в dist): таймаут аттрактора в секундах
   (по умолчанию 90), стартовый год (последний), координаты точки отправления
   (Новороссийск 44.72, 37.77), путь к видео корабля `assets/video/ship.mp4`, цвета.

6. **`README.md`** простым языком по-русски: как запустить, как заменить данные
   (положить новый xlsx, запустить build_data, запустить build_dist),
   как подменить видео, где настройки.

7. Это задание — `docs/spec-block2-export.md`.

## Макет и поведение

Фон экрана светло-серый, поверх — белая карточка с мягкой тенью и скруглением,
внутри всё содержимое. Стиль минималистичный, много воздуха, системный шрифт
(Inter), акцент синий `#2F6FED`, маршруты зелёные, глобус светлый: суша
светло-серая с тонкими серыми границами, океан почти белый, Россия чуть выделена.
Никаких тёмных «космических» глобусов.

### Состояние A «Карта»

- Слева вверху заголовок «Страны назначения». Под ним поле поиска
  «Поиск по странам» и прокручиваемый список стран (синие ссылки),
  отсортированный по объёму за выбранный год по убыванию; поиск фильтрует
  список по подстроке. Под списком подпись «Выберите страну».
- В центре и справа большой глобус. От точки отправления (Новороссийск)
  к каждой стране с объёмом больше нуля в выбранном году идёт дуга-маршрут
  (great circle, приподнятая над поверхностью, зелёная; толщина и прозрачность
  зависят от объёма по логарифмической шкале). В конечной точке — маркер.
  Маршруты прорисовываются анимированно от РФ к стране при смене года.
  Глобус медленно вращается сам, пока его не трогают. Тач: одним пальцем —
  вращение, двумя — зум (мультитач обязателен); мышь работает для разработки.
- Справа вверху карточка-сводка: заголовок-«селект» «Экспорт зерна, 2025»
  со стрелкой — по нажатию карточка сворачивается и разворачивается. Внутри:
  крупно общий объём с подписью «поставлено на экспорт», рядом два числа —
  количество стран («стран-получателей») и количество групп продукции
  («групп продукции»); ниже «Топ-3 направлений» — три строки (страна, объём),
  по нажатию открывается маршрут этой страны.
- Внизу таймлайн: годы 2014…2025 «пилюлями» на одной линии, выбранный год —
  синий залитый. Тап по году перерисовывает маршруты, сводку и список.
  Слева от таймлайна круглая кнопка с иконкой глобуса — сброс вида
  (вернуть вращение и стандартный зум).
- Тап по дуге, по маркеру страны на глобусе или по стране в списке ведёт
  в состояние B. Для попадания пальцем по дугам используются невидимые
  «толстые» hit-геометрии (TubeGeometry радиусом больше видимой);
  при попадании в несколько выбирается ближайшая, приоритет у маркера страны.
- Выбор страны в списке: строка раскрывается в карточку с названием, крестиком
  и синей кнопкой «Начать путь» → состояние B. Крестик — отмена.

### Состояние B «Путь»

- Левая треть карточки — панель с видео корабля: `<video>` autoplay muted loop,
  источник из config. Пока видео нет — заглушка: серый блок с кнопкой Play
  посередине, подпись «Видео: путь корабля» и лёгкая процедурная анимация
  (canvas: море, волны, силуэт судна). Если видео не загрузилось (onerror) —
  автоматически заглушка.
- Глобус плавно (около секунды) поворачивается и приближается так, чтобы
  маршрут РФ → страна был в кадре целиком. Остальные маршруты гаснут,
  выбранный — яркий зелёный с анимированной точкой-«кораблём», идущей по дуге в цикле.
- Справа карточка страны: название, крупно объём за выбранный год,
  рядом место в рейтинге года с подписью «среди стран-получателей»,
  ниже список продукции за этот год в две колонки мелким шрифтом
  («Пшеница 4 275 тыс. т»; первая буква заглавная), максимум 14 позиций,
  остальное — «и ещё N позиций».
- Внизу слева кнопка-глобус и кнопка «← К карте» — возврат в состояние A
  с обратной анимацией камеры. Таймлайн в состоянии B скрыт, но год остаётся выбранным.

### Аттрактор

При бездействии дольше таймаута из config — возврат в состояние A,
год = стартовый, выделение снято, автовращение восстановлено.
Любое касание сбрасывает таймер.

## Общие требования

- Разрешение 1920×1080 фиксированное, но вёрстка масштабируется:
  корневой контейнер сжимается через `transform: scale` под окно с сохранением 16:9,
  чтобы всё влезало в браузере разработчика.
- Курсор и hover не обязательны, но не должны ломать тач.
- Никаких запросов в интернет.
- Производительность: 60 fps при примерно 120 дугах. TubeGeometry для дуг допустима.
- Разделитель тысяч — тонкий пробел; для чисел больше 100 десятичные не показываются,
  для меньших — одна десятичная.
